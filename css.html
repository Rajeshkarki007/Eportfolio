CSS transforms plain HTML into beautiful, responsive, and animated web experiences. It controls everything from colours and typography to complex layouts and smooth animations.

Styling

Colours & CSS Variables

CSS custom properties (variables) allow you to define reusable values — making themes, dark mode, and design consistency effortless.

:root {
  --accent: #00e5ff;
  --bg: #07090f;
  --text: #e8edf8;
  --radius: 14px;
}
.button {
  background: var(--accent);
  border-radius: var(--radius);
}

Responsive Design

Media Queries

Media queries allow CSS to adapt to different screen sizes, orientations, and device capabilities — the foundation of responsive web design.

/* Mobile first — default styles */
.container { padding: 1rem; }
.hero-title { font-size: 2rem; }

/* Tablet (≥ 768px) */
@media (min-width: 768px) {
  .hero-title { font-size: 3rem; }
}

/* Desktop (≥ 1024px) */
@media (min-width: 1024px) {
  .hero-title { font-size: 4.5rem; }
  .container { max-width: 1200px; }
}
