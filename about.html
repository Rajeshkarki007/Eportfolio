What is Full Stack
Development?

Full stack development is the ability to work on both the frontend and the backend of a web application mastering the complete technology "stack".

The Two Sides

Frontend vs Backend

🎨

Frontend

The frontend is everything a user sees and interacts with directly in their browser. It is responsible for the layout, design, animations, and user experience of a website.

Technologies
HTML5 CSS3 JavaScript Bootstrap React Vue.js
Runs in the browser. The user downloads and executes this code on their own device.
HTTP / API
JSON / Data
⚙️

Backend

The backend is the server-side of a web application. It handles data storage, business logic, user authentication, and exposes APIs that the frontend consumes.

Technologies
PHP Node.js Python MySQL MongoDB REST API
Runs on the server. Users never see this code it stays private and secure on the server.

Backend in This Module
