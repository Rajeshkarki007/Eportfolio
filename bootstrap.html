Accordion Component

Bootstrap is a free, open-source CSS framework directed at responsive, mobile-first front-end web development. It contains HTML, CSS and JavaScript-based design templates.

Bootstrap uses a 12-column flex-based grid. Wrap columns in a .row, and use classes like col-md-6 to define responsive widths at different breakpoints.

Utility classes are single-purpose CSS classes for common properties: d-flex, p-3, text-center, fw-bold, rounded-pill no custom CSS needed.
Modals & Interactive Components

Bootstrap provides out-of-the-box JavaScript components modals, tooltips, dropdowns, toasts all triggered with data attributes, no custom JS required.

<!-- No JavaScript needed! -->
<button
  data-bs-toggle="modal"
  data-bs-target="#myModal">
  Open Modal
</button>
