HTML — HyperText
Markup Language

HTML is the skeleton of every webpage. It defines the structure and semantics of content using a system of elements, tags, and attributes. Every website you've ever visited is built on HTML.

Core Concepts

HTML Fundamentals

🏷️
Elements & Tags

HTML is written using tags wrapped in angle brackets. Most elements have an opening and closing tag.

<p>Hello World</p>
<h1>Heading</h1>
<img src="img.png"/>
⚙️
Attributes

Attributes provide additional information about elements and are placed inside the opening tag.

hrefsrcclassidalttypenameplaceholderrequired
🧠
Semantic HTML

Semantic elements clearly describe their meaning — improving SEO, accessibility, and code readability.

<header><nav><main><article><footer>
♿
Accessibility

Good HTML is accessible to all users, including those using screen readers. Use ARIA roles and descriptive attributes.

aria-labelroletabindexlang
