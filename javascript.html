JavaScript
The Language of the Web

JavaScript is what makes webpages dynamic and interactive. It runs in the browser, manipulates the DOM, handles events, validates forms, makes API calls, and brings the entire web experience to life.

Core Concepts

JavaScript Fundamentals

📦
Variables & Data

Store and manipulate data using const, let, and various data types.

const name = "Alex";
let score = 0;
const isActive = true;
🔧
Functions

Reusable blocks of code. Declare once, call anywhere. ES6 arrow functions are concise and modern.

const greet = (name) => {
  return `Hello ${name}`;
};
greet("World");

DOM Manipulation

The Document Object Model lets JS read and change HTML elements in real time.

const el =
 document.querySelector("h1");
el.textContent = "New!";

Button Click Effects

Ripple Effect Demo

A ripple animation is created dynamically using JavaScript — calculating the click position and injecting a ripple element into the DOM.

btn.addEventListener("click", (e) => {
  const ripple = document.createElement("span");
  ripple.className = "ripple";
  // Position & size from click coords
  btn.appendChild(ripple);
});
